1. Mệnh đề Logic và Tập hợp

Mệnh đề là một khẳng định có giá trị chân lý xác định (Đúng hoặc Sai). Các phép toán logic cơ bản:

  • Phép phủ định (¬P): Ngược giá trị chân lý của P.
  • Phép hội (P ∧ Q): Đúng khi cả P và Q đều đúng.
  • Phép tuyển (P ∨ Q): Sai khi cả P và Q đều sai.
  • Phép kéo theo (P → Q): Chỉ sai khi P đúng và Q sai.

2. Giải thuật Tìm kiếm Nhị phân (Binary Search)

Giải thuật tìm kiếm trên mảng đã sắp xếp với độ phức tạp thời gian cực đại là O(log n).

def binary_search(arr, low, high, x):
    if high >= low:
        mid = (high + low) // 2
        if arr[mid] == x:
            return mid
        elif arr[mid] > x:
            return binary_search(arr, low, mid - 1, x)
        else:
            return binary_search(arr, mid + 1, high, x)
    else:
        return -1
